CS 370 – Pirate Intelligent Agent
Project Overview
For my CS 370 Artificial Intelligence course at Southern New Hampshire University, I developed the training logic for a pirate intelligent agent in a treasure hunt game. The pirate's goal is to find a path through a maze and reach the treasure. This project demonstrates how reinforcement learning and neural networks can help an agent learn from its experiences and improve its decisions over time.
What Code Was Provided, and What Did I Create?
I was given a starter Jupyter Notebook, along with two Python files: `TreasureMaze.py` and `GameExperience.py`. The maze file provided the game environment, including movement, rewards, and game status. The experience file supported storing past experiences and retrieving training data. The starter notebook also contained supporting code and instructions for the deep Q-learning model.
My main responsibility was to complete the `qtrain()` function in the notebook. I implemented the training loop so the pirate could begin at different locations, explore valid moves, and use the neural network's predictions to choose actions. I also added experience replay, tracked wins and losses, updated the target network, and adjusted the exploration rate as training progressed. Finally, I used the provided `completion_check()` function to evaluate whether the pirate could reach the treasure from every valid starting location. I left the supplied Python support files unchanged.
What Do Computer Scientists Do, and Why Does It Matter?
Computer scientists design, develop, test, and improve technology to solve problems. Their work involves much more than writing code. They also analyze information, choose suitable algorithms, and consider how technology affects people. This matters because computer science supports important tools in areas such as healthcare, transportation, communication, and business. In this project, I learned how artificial intelligence can be used to improve decisions through training and feedback instead of relying only on fixed instructions.
How Do I Approach a Problem as a Computer Scientist?
I start by understanding the problem, identifying the requirements, and breaking the work into smaller steps. For the pirate intelligent agent, I first reviewed the starter code to understand how the maze environment, rewards, and experience replay worked together. Then I implemented the deep Q-learning process and examined training results to identify areas that needed improvement. I also learned the importance of debugging carefully. For example, the replay system needed a Boolean value to distinguish completed episodes from ongoing ones so the model could calculate training targets correctly. This experience showed me why testing, reviewing results, and improving code are essential parts of solving problems.

Although this project is a game, the same principles apply to real-world AI systems where incorrect decisions can have serious consequences.
