
# CS 370 - Pirate Intelligent Agent

## Project Overview

This project was completed for CS 370: Artificial Intelligence at Southern New Hampshire University.

The objective was to train an intelligent agent to navigate a maze and reach a treasure location using deep Q-learning.

## Technologies

- Python
- Jupyter Notebook
- TensorFlow / Keras
- NumPy
- Matplotlib

## How It Works

The pirate learns by interacting with a maze environment.

1. The pirate starts at a location in the maze.
2. It chooses a movement: left, right, up, or down.
3. The environment provides feedback through rewards.
4. The agent uses a neural network to estimate the value of different actions.
5. Training helps the agent improve its decisions.

The notebook also includes functions for evaluating whether the agent can reach the treasure from valid starting positions.

## Project Files

- `Lin_Jason_ProjectTwo.ipynb` - Main project notebook containing the training and testing logic.

## Running the Project

The notebook requires Python, Jupyter, TensorFlow/Keras, NumPy, Matplotlib, and the course-provided `TreasureMaze.py` and `GameExperience.py` modules.
